# Changelog

## 0.1.0
- Initial release
- Condition-over-duration core rule, with the actionability matrix that explains why most waits are redundant
- Decision table mapping "what you're waiting for" to the API that waits for it
- Timeout budget: what each timeout bounds and how to read the error it produces
- Reference recipes per signal type — element state, network, events, `page.clock`, eventual consistency, overlays, frames
- Anti-pattern catalogue with a grep-based audit
- Annotated `playwright.config.ts` baseline and a flake triage playbook
