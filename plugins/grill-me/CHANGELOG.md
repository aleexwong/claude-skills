# Changelog

## 0.1.0
- Initial release
- Decision-impact ranking: a question is asked only when a different answer changes the work
- Seven territories where fog hides: outcome, why now, one user one moment, edges, immovables, failure appetite, done
- Question craft toolkit — forced choice, attached consequences, scenarios over categories, episodes over averages
- "I don't know" escalation path that converts unknowns into defaults with invalidation triggers
- Concrete playback step before the brief is written
- Sanity check / Standard / Deep tracks (~3 / ~8 / ~15 questions), Deep adding pre-mortem and kill criteria
- Brief template separating Decided, Assumed, and Open, each carrying its source or its cost
